# Maze Generator

Игра на языке C: генерация лабиринта заданного размера и его прохождение. Графика — raylib.

Авторы: paulxcalder, DaniiarAbd.

## Возможности

- генерация лабиринта от 3×3 до 100×100, случайно или по заданному seed;
- проверка наличия пути от старта до выхода;
- ручное прохождение и показ решения («Авто-проход»);
- таблица рекордов;
- журнал событий в файле.

## Структура

| Файл | Назначение |
|---|---|
| `main.c` | точка входа |
| `graphic.c`, `graphic.h` | интерфейс и отрисовка |
| `labyrinth.c`, `labyrinth.h` | генерация лабиринта и поиск пути |
| `db.c`, `db.h` | таблица рекордов (`scores.dat`) |
| `error.c`, `error.h` | журнал событий (`maze.log`) |
| `build.bat` | сборка под Windows |
| `DejaVuSansBold.ttf` | шрифт интерфейса |

## Сборка

Требуются GCC (MinGW) и raylib.

```bat
build.bat
```

или

```bat
gcc main.c graphic.c labyrinth.c error.c db.c -lraylib -lopengl32 -lgdi32 -lwinmm -o test.exe
```

Файл `DejaVuSansBold.ttf` должен находиться рядом с исполняемым файлом.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | движение |
| `R` | вернуться на старт; на экране победы — новый лабиринт |
| `M` | к настройкам |
| `Esc` | выход |

## Оптимизация

| Оптимизация | Результат |
|---|---|
| Поиск пути без повторного обхода клеток | сложность генерации O(2^W) → O(W·H) |
| Карта в одном блоке памяти | вызовов `malloc` на лабиринт: H + 1 → 2 |
| Отрисовка лабиринта через текстуру | время кадра 100×100: 1,06 → 0,17 мс |
| Координаты выхода сохраняются при генерации | поиск выхода O(W·H) → O(1) |
