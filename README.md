# MAZE_GENERATOR

**MAZE_GENERATOR** — это игра про генерацию и прохождение лабиринтов. Проект сочетает в себе процедурную генерацию, поиск решения и графический интерфейс на `raylib`. Игрок задаёт размеры лабиринта, получает случайно созданную карту и проходит её от точки старта до выхода.

---

## 1. Об игре

Игра посвящена исследованию лабиринта, который создаётся автоматически при запуске. Главная идея проекта — показать, как можно построить случайный, но при этом решаемый лабиринт, а затем визуально представить его в удобном интерфейсе.

В текстовой части проекта лабиринт генерируется в виде двумерного массива символов, а затем проверяется наличие пути от старта к выходу. В графической части пользователь взаимодействует с меню, задаёт параметры поля и знакомится с основными режимами игры.

Особенности проекта:

- случайная генерация лабиринта;
- наличие входа и выхода;
- поиск единственного корректного пути;
- графическое меню с несколькими экранами;
- настройка размеров лабиринта вручную;
- использование `raylib` для отрисовки интерфейса.

## 3. Функциональные возможности

### 3.1 Главное меню

Главное меню выполнено в графическом стиле и содержит основные разделы проекта:

- **Играть** — переход к настройке лабиринта;
- **Помощь** — экран с правилами и управлением;
- **Справка** — экран с информацией об авторах и учебных данных проекта;
- **Выход** — завершение работы приложения.

Интерфейс меню построен на прямоугольных кнопках с подсветкой при наведении курсора.

### 3.2 Генерация лабиринта

Лабиринт создаётся автоматически на основе заданных пользователем ширины и высоты. В проекте используется двумерная карта символов:

- `@` — стена;
- пробел — проход;
- `#` — клетка, входящая в найденный путь;
- `v` — посещённая клетка при поиске решения.

Размеры лабиринта ограничены значениями до `100 x 100`. После генерации создаётся выход на нижней границе карты, а затем запускается проверка наличия пути от старта к выходу.

### 3.3 Игровой процесс

Игровой процесс строится вокруг следующих действий:

1. пользователь задаёт размеры лабиринта;
2. игра генерирует карту;
3. выполняется поиск корректного маршрута;
4. игрок получает лабиринт с отмеченным решением либо проходит его вручную в графической версии.

В текущей реализации есть также заготовки для дополнительных режимов:

- **в одиночку**;
- **бот против бота** — режим пока находится в разработке;
- **ввод ключа / seed** — функция также отмечена как разрабатываемая.

## 4. Алгоритмы

В основе проекта лежат два ключевых алгоритма.

### Генерация лабиринта

Лабиринт строится по сетке с чередованием стен и проходов. Сначала создаётся рамка из стен по периметру, затем внутри формируется структура из ячеек, после чего между ними случайным образом пробиваются проходы. Такой подход позволяет получать случайную конфигурацию при сохранении общей связности карты.

### Поиск пути

Для поиска выхода используется рекурсивный обход в глубину (DFS). Функция проверяет соседние клетки в четырёх направлениях:

- вправо;
- вниз;
- влево;
- вверх.

Если найден путь к выходу, клетки на маршруте помечаются символом `#`. Если путь не найден, поиск повторяется на новой сгенерированной карте.

## 5. Логика игры

Логика проекта разделена на два уровня:

### Консольная часть

В `labyrinth.c` реализованы:

- динамическое выделение памяти под карту;
- заполнение массива стенами и проходами;
- случайная генерация структуры лабиринта;
- поиск пути от старта к выходу;
- освобождение памяти после работы.

### Графическая часть

В `graphic.c` реализована логика экранов:

- главное меню;
- выбор режима игры;
- экран настройки лабиринта;
- справка;
- помощь;
- заготовки под дополнительные режимы.

Состояние интерфейса переключается через перечисление `Screen`, а работа с кнопками построена на проверке положения мыши и нажатий.

---

## 6. Интерфейс

Интерфейс выполнен в тёмной стилистике с акцентными цветами для кнопок и заголовков. В проекте используются:

- крупные заголовки;
- центрирование текста;
- подсветка элементов при наведении;
- отдельные экраны для разных режимов;
- удобные поля ввода ширины и высоты;
- визуальное отображение выбранного размера.

Основные экраны:

- **MENU** — стартовое меню;
- **MODE_SELECT** — выбор режима;
- **GAME** — настройка размеров лабиринта;
- **ABOUT** — сведения об авторах и проекте;
- **HELP** — правила и управление;
- **BOT_VS_BOT** — режим в разработке;
- **KEY_INPUT** — ввод ключа, также в разработке.

---

## 7. Управление

Управление в графической версии описано в разделе помощи и включает:

- `W` / стрелка вверх — движение вверх;
- `S` / стрелка вниз — движение вниз;
- `A` / стрелка влево — движение влево;
- `D` / стрелка вправо — движение вправо;
- `Esc` — пауза / возврат в меню;
- `R` — рестарт уровня.

При работе с меню также используются:

- левая кнопка мыши — выбор кнопок и полей ввода;
- клавиатура — ввод числовых значений ширины и высоты.

## 8. Архитектура проекта

Проект состоит из двух логически связанных модулей.

### `labyrinth.c`

Отвечает за:

- хранение карты в `char**`;
- генерацию лабиринта;
- поиск решения;
- вывод результата в консоль;
- очистку динамической памяти.

### `graphic.c`

Отвечает за:

- запуск окна `raylib`;
- отрисовку интерфейса;
- обработку ввода пользователя;
- переключение между экранами;
- показ справки и информации о проекте.

### Ключевые сущности

- `map` — двумерная карта лабиринта;
- `width`, `height` — размеры поля;
- `x_end`, `y_end` — координаты выхода;
- `wall`, `way`, `right_way`, `visited` — символы состояния клетки;
- `Screen` — перечисление экранов интерфейса.

## 9. Сборка

### Требования

- компилятор C с поддержкой стандарта **C11**;
- библиотека **raylib**;
- подключённый шрифт `DejaVuSansBold.ttf` рядом с исполняемым файлом.

### Пример сборки

```bash
gcc -std=c11 labyrinth.c -o labyrinth

gcc -std=c11 graphic.c -o maze_generator -lraylib -lm -lpthread -ldl -lrt -lX11
```

Если `raylib` установлена в нестандартном месте, пути и флаги линковки могут отличаться.

### Запуск

После сборки запустите получившийся исполняемый файл. Для графической версии важно, чтобы рядом с программой находился файл шрифта:

```bash
DejaVuSansBold.ttf
```
